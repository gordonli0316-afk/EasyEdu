# seed_courses/ — bundled sample question bank

This directory ships with the repository so that **EasyEdu works immediately after
cloning, with no GPU, no API key and no data pipeline**.

`data/courses/` is where the full AP/IB bank generated by
`scripts/ingest_textbooks.py` lives. That directory is not committed (the textbooks
it is generated from are far too large for git). Whenever `data/courses/` is empty,
`CoursesDataLoader` automatically falls back to this sample bank and logs:

```
ℹ️  .../data/courses 中没有题库，改用内置示例题库 .../data/seed_courses
```

The pages then show 4 courses / 8 chapters / 23 questions instead of an empty site.

## Contents

```
AP/ap_statistics/          AP Statistics
AP/ap_physics/             AP Physics 1
IB/ib_biology/             IB Biology
IB/ib_computer_science/    IB Computer Science
```

Each course uses the same layout the ingest script produces:

```
<COURSE>/<slug>/
├── chapters.json                          # chapter list; "knowledge_points" is required
├── knowledgepoints/all_knowledgepoints.json
└── questions/*.json                       # any number of files; each question needs "chapter"
```

## Rules for this data

- Question ids and knowledge-point ids are **globally unique** here
  (`ap_stats_ch01_q1`), because the loader only rewrites chapter ids.
- Every question needs a `chapter` field matching a chapter `id` in the same book,
  otherwise it will not appear under that chapter.
- Every chapter needs a `knowledge_points` array (may be empty, but the key must exist).
- Questions are real AP/IB-style items with a worked reference answer. The offline
  demo tutor answers from `reference_answer.content` / `reference_answer.explanation`,
  so those fields must stay accurate — do not put placeholder text in them.

To use your own generated bank instead, just populate `data/courses/`. It always
takes priority over this directory.
